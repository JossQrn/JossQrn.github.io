The game

Blue Oath is a top-down action-adventure game. You play a warrior swordfish setting out to free a giant cursed moray eel that wanders the ruins of its temple.

Powerful dash attacks impale enemies and objects onto your beak. Stack them, then throw them back as weapons or tools.

Technical design

  • Designed and implemented the 3Cs and core gameplay systems
  • Set and maintained technical guidelines and documentation
  • Developed procedural animation systems
  • Built data-driven systems for fast iteration and tuning

Game design

  • Designed and balanced combat encounters and arena progression
  • Contributed to enemy design, behaviors and tuning

Project management

  • Coordinated planning and acted as design liaison with the pedagogy team
  • Helped with scope planning and production organization
Scripting & design

3Cs evolution

I implemented the 3Cs directly in engine. The main challenges were:

Balancing aquatic movement with combat responsiveness
Making a plane-constrained character feel like a freely swimming fish
Creating reusable mechanics that support both combat and puzzles

Procedural animation with Control Rig

To support the animation pipeline, I built procedural systems for the swordfish's turning and a spline-based locomotion for the moray. Animators could blend handcrafted animation on top of the procedural motion.

Enemies

Worked with the AI Designer on enemy design: defined gameplay intentions and implemented behaviors. Built a State Tree and Gameplay Ability System architecture to drive them, then iterated on encounter pacing and difficulty from playtest data.

Game feel

Refined player feedback with procedural animation, controller rumble and camera shake.

Tooling

Bug reporter

  • Engine-integrated bug reporting connected to the team's task tracker
  • Captures contextual data straight from the engine
  • Sends automated HTTP requests that create tasks and stories
Project management

Owned project planning and scope definition, working with each team member to align goals, constraints and production milestones.

The game

EyePiece is a single-player narrative detective game. You investigate a murder that hasn't happened yet, exploring different temporalities to discover what happened that day.

Technical design

  • Built tools and Blueprint templates while overseeing code architecture
  • Debugged, profiled and fixed systems
  • Implemented interaction, inspection and time-based save systems

Project management

  • Coordinated planning and communication for the design team
Tooling

Temporality switcher

One of the most effective tools on the project. It gave the team:

  • An instant preview of every temporal state
  • A fast way for designers to validate gameplay flow
  • Per-temporality lighting and asset tweaks for artists

It removed guesswork and sped up iteration.

Polaroid creator

Generates every asset used by the teleportation mechanic:

  • Creates Polaroid textures from scene captures
  • Auto-generates the data assets
  • Updates existing photos with no manual setup
Gameplay systems · Blueprint & C++

Narrative 3Cs

Character, camera and controls tuned for slow, attentive investigation.

Inspection system

Pick up and examine evidence up close.

Interaction & inventory

A shared interaction layer feeding the player's inventory.

Project management

Wrote design proposals and planning docs in pre-production, and helped present the final project at the showcase.
